# Online Feedback Form

A simple and styled online feedback form for a local café website, built using **HTML** and **CSS**. This form allows customers to provide their name and feedback in a clean, user-friendly interface.

---

## 🎯 Project Overview
This project is designed to collect customer feedback for a café.  
It demonstrates basic form structure, layout, and styling techniques using HTML and CSS.

The form includes:
- A main heading “We Value Your Feedback”
- Text input for customer’s name
- Textarea for comments
- A submit button with styled hover effect

---

## 🧱 Technologies Used
- **HTML5** — For structure and form elements  
- **CSS3** — For styling, layout, and visual appeal  

---

## ⚙️ Features
- Centered form with width of 400px  
- Light background and soft border for the form  
- Heading styled in dark green and center-aligned  
- Inputs and textarea styled with padding and spacing  
- Submit button styled with background color, rounded corners, and hover effect  
- Box-sizing applied globally to ensure proper sizing
